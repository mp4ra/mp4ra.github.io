# Item Properties

Item properties are small data records stored in the `ItemPropertyContainerBox` ('ipco') and associated with items via the `ItemPropertyAssociation` ('ipma'). Each property is identified by its box type and provides descriptive or transformative metadata for the associated item.

See also the consolidated [Items](/registered-types/items) page.
